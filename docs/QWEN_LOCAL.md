# 로컬 Qwen Vision 설정 및 사용

## 목적

Qwen3-VL을 Ollama로 로컬 실행해 판서 이미지 재검토와 강의 핵심 개념 선별을 수행한다. OpenAI API 키나 외부 AI API 호출은 필요하지 않다. 모델을 처음 내려받을 때만 인터넷 연결이 필요하다.

## 기본 모델

- 기본 모델: \`qwen3-vl:4b\`
- Ollama 라이브러리의 Qwen3-VL 4B 태그
- 모델 저장소에서 안내하는 다운로드 크기: 약 3.3GB
- 이미지와 텍스트 입력 지원
- Ollama 최소 버전: 0.12.7
- Ollama의 모델 저장 공간을 사용한다. 저장소의 \`models/\` 폴더에 직접 복사하지 않는다.

공식 모델 안내: https://ollama.com/library/qwen3-vl

기본 모델을 바꾸려면 실행 전에 \`LECTURE2DOC_QWEN_MODEL\`을 설정한다. 예를 들어 8B 모델은 더 많은 메모리와 저장 공간을 요구한다.

\`\`\`bash
export LECTURE2DOC_QWEN_MODEL=qwen3-vl:8b
\`\`\`

## 설치 및 최초 다운로드

1. macOS용 Ollama를 https://ollama.com/download 에서 설치한다.
2. Ollama 앱을 실행한다. 로컬 API 서버가 기본 주소 \`http://127.0.0.1:11434\`에서 동작해야 한다.
3. Ollama 0.12.7 이상인지 확인한다.

\`\`\`bash
ollama --version
\`\`\`

4. Lecture2Doc 가상환경을 활성화하고 모델을 내려받는다.

\`\`\`bash
cd ~/Lecture2Doc
source .venv/bin/activate
lecture2doc qwen-models
\`\`\`

기본 명령은 \`qwen3-vl:4b\`를 내려받는다. 다른 크기를 선택하려면 다음처럼 실행한다.

\`\`\`bash
lecture2doc qwen-models --model qwen3-vl:8b
\`\`\`

모델 다운로드는 수 GB가 필요하다. 모델 파일은 Ollama가 관리하며 GitHub에 올라가지 않는다.

## 기존 강의에서 판서 재검토

1. Lecture2Doc 서버를 실행한다.
2. 기존 강의를 열고 원하는 판서 페이지를 선택한다.
3. C · 판서 텍스트의 **Qwen 판서 재검토**를 누른다.
4. 기존 OCR 결과 아래에 Qwen 결과가 별도로 표시되는지 확인한다.

Qwen은 선택된 판서 이미지와 기존 OCR 텍스트 후보를 함께 읽는다. 결과에는 다음이 포함된다.

- 판서의 읽기 순서를 유지한 텍스트 블록
- 한국어·영어·수식 유형 구분
- 수식의 LaTeX 후보
- 시각적 판독 신뢰도(높음·보통·낮음)
- 판독하기 어려운 영역과 비고

**Qwen 결과는 기존 OCR을 덮어쓰지 않는다.** 기존 인식 영역, 좌표, TXT/JSON, 원본 crop은 보존하고 \`qwen_review\`에 AI 재검토 결과를 추가한다. 따라서 두 결과를 비교하고 사람이 확인할 수 있다.

## 강의 핵심 개념 선별

학습 분석의 개념 선별도 동일한 Qwen 모델을 텍스트 모드로 사용한다. 판서 OCR 후보, 전사문 일부, 반복 횟수와 출처 정보를 입력해 강의 주제를 파악하고 최대 5개 핵심 개념을 선별한다.

- 일반 표현·말버릇을 제외한다.
- 입력 후보에 없는 개념을 새로 만들지 않는다.
- 기존 음성 등장 시각과 판서 페이지 연결을 보존한다.
- 중요도 점수는 여전히 근거 기반 규칙으로 계산한다.

학습 분석의 **분석 다시 실행** 버튼을 누르면 Qwen 개념 선별도 다시 수행한다.

## 로컬 실행과 네트워크

- 추론 요청은 \`127.0.0.1\`의 Ollama 서비스로만 보낸다.
- OpenAI 등 외부 AI API로 텍스트나 이미지가 전송되지 않는다.
- 최초 모델 다운로드에는 인터넷이 필요하다.
- 모델이 설치된 후에는 Ollama 로컬 서버와 Lecture2Doc을 네트워크 없이 사용할 수 있다.
- 로컬 추론은 Mac의 메모리·GPU/CPU·전력을 사용하며, 모델 크기와 이미지 해상도에 따라 처리 시간이 달라진다.

## 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| \`LECTURE2DOC_QWEN_MODEL\` | \`qwen3-vl:4b\` | 사용할 로컬 Qwen 모델 |
| \`LECTURE2DOC_OLLAMA_URL\` | \`http://127.0.0.1:11434\` | Ollama 로컬 API 주소 |

## 오류 해결

- **Ollama 명령을 찾을 수 없음:** Ollama macOS 앱을 설치하고 실행한 뒤 새 터미널에서 다시 확인한다.
- **Ollama 연결 실패:** 앱이 실행 중인지 확인하고 \`http://127.0.0.1:11434/api/version\`을 확인한다.
- **모델을 찾을 수 없음:** \`lecture2doc qwen-models\`를 다시 실행한다.
- **메모리 부족 또는 처리 지연:** \`qwen3-vl:4b\`를 사용하거나 다른 앱을 종료한다. 더 큰 모델로 바꾸기 전에 실제 메모리 여유를 확인한다.
- **Qwen 결과가 틀림:** 결과는 보조 판독이며 원본 이미지와 기존 OCR을 함께 비교한다. 읽을 수 없는 부분은 자동으로 정답처럼 보정하지 않는다.
