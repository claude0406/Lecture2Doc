# 강의 중요도와 개념 시간 연결

## 목표

강의를 처음부터 끝까지 다시 시청하지 않아도 핵심 내용을 파악하고 필요한 구간만 재생할 수 있도록, 기존 판서 페이지와 음성 전사를 연결한다.

이 기능은 강의를 짧게 요약해 원본을 대체하려는 기능이 아니다. 원본 판서·전사·영상 시간 정보를 보존하면서 학습 우선순위와 다시 확인할 시점을 제공한다.

## 제공 기능

1. **판서 구간 중요도**: 페이지별 음성 강조 표현, 관련 개념의 반복 언급, OCR 필기와 음성의 일치 신호를 종합해 0~100 점수와 근거를 표시한다.
2. **필기와 음성 연결**: 해당 판서가 나타나는 시간에 겹치는 발언과, 판서에서 추출한 개념을 실제로 언급하는 발언을 함께 연결한다.
3. **개념별 등장 시간**: OCR 필기에서 추출한 개념을 음성 전사 전체에서 찾아 발언 시작·종료 시간을 기록한다. 필기 페이지가 나타난 시간 범위도 별도로 제공한다.
4. **영상 이동**: 화면에서 시간 구간을 선택하면 원본 영상의 해당 시점으로 이동한다.

## 중요도 계산 기준

현재 구현은 추가 모델이나 외부 API 없이 실행되는 규칙 기반 1차 버전이다. 점수는 다음 근거를 반영한다.

- 강의자의 강조 단서: 시험·출제, 중요·핵심, 기억·암기, 주의, 정의·공식, 유도·증명, 예제·문제 풀이 표현
- 반복성: 판서의 개념어가 음성 전사 여러 구간에서 반복되는 정도
- 교차 근거: OCR로 읽은 판서 개념이 음성 전사에서도 확인되는 정도
- 판서 근거: 페이지에서 OCR 텍스트가 확인되는 정도

점수 구성은 사용할 수 있는 데이터에 따라 달라진다. 음성 전사가 없으면 교수자의 설명 중요도를 산정하지 않고 '근거 부족'으로 표시한다. OCR이 없으면 음성 내 반복·강조 신호를 이용한 부분 분석만 수행한다. 점수는 정답 확률이나 시험 출제 가능성을 뜻하지 않는다.

## 시간 정보 해석

- **필기 시간**: 기존 페이지 정리 결과의 `start`~`end` 범위다. 해당 판서 상태가 영상에서 관측되는 구간이며, 모든 글자가 정확히 처음 작성된 순간을 뜻하지는 않는다.
- **음성 시간**: 자막 또는 Whisper 전사 세그먼트의 `start`~`end` 범위다. 이 안에서 개념어가 실제 텍스트로 일치하는 경우를 연결한다.
- **판서 시간 구간 연결**: 필기 시간과 겹치는 전사 구간은 관련 개념어가 직접 일치하지 않아도 문맥 확인용으로 연결한다.
- **개념 언급 연결**: 필기 시간 바깥에서 발언하더라도 OCR 개념어가 음성 텍스트에 일치하면 별도의 개념 언급으로 연결한다.

모든 시간은 영상 시작을 0초로 하는 초 단위이며 기존 전사 및 프레임 시간 계약을 따른다.

## 데이터 위치

최종 결과는 `manifest.json`의 `learning_analysis`에 저장된다.

- `status`: `complete`, `partial`, `insufficient_evidence`, `failed`
- `pages[]`: 페이지별 중요도, 판단 근거, 연결된 전사 구간, 개념 목록
- `concepts[]`: 전체 개념별 중요도, 음성 등장 구간, 필기 등장 페이지
- `speech_occurrences[]`: 세그먼트 ID, 시작·종료 시간, 원문 발언
- `board_appearances[]`: 페이지 ID, 페이지 시작·종료 시간, OCR 근거

분석 결과는 독립된 `learning-analysis` 단계 캐시에 저장한다. 원본 영상, 기존 페이지, 음성 전사 또는 OCR이 바뀌면 캐시 지문이 달라져 새 분석이 수행된다. CLI의 `--rerun learning-analysis` 옵션으로 이 단계만 다시 실행할 수 있다.

## 한계 및 다음 개선 후보

현재는 형태소 분석이나 의미 임베딩을 사용하지 않으므로, 같은 뜻의 다른 표현이나 조사·어미 변화가 큰 표현을 놓칠 수 있다. OCR 오인식은 개념 추출과 매칭 정확도에 영향을 준다. 음성 전사의 시간 경계도 실제 발화의 정확한 단어 경계와 다를 수 있다.

중요도 점수는 설명 가능한 초기 휴리스틱이다. 실제 강의와 사람이 선정한 중요 구간을 비교해 가중치를 조정해야 한다. 이후에는 수식·정의·예제의 구조적 역할, 교수자 강조 방식, 반복되는 개념의 맥락을 추가로 고려할 수 있다.
