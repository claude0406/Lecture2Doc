# A/B 원인 추적·수정·실제 재평가 (2026-11-02)

A의 누적 판서 선택과 B의 관측 기반 복원을 수정하고 실제 영상을 재실행했다. **C는 시작하지 않았다.** 완료된 기능과 일반 영상에서의 완성도를 구분한다. 새 모델이나 의존성은 추가하지 않았다.

[전체 이미지·후보·출처 비교](../experiments/ab-refinement/review/index.html)에서 GT·가장 가까운 원본·이전 A·새 A/B, 개선·악화 사례, 영역 지도를 확인할 수 있다. 이전 `experiments/accessmath/`, `board-pages/`, `page-restoration/`는 보존했다. 이번 기준 출력은 `experiments/ab-refinement/accepted/`이다. `verified/`, `validated/`, `current/` 등은 중간 버전이며 최종 비교에 사용하지 않는다.

## 실제 결과

기존 `accessmath_evaluate.py`의 이진화, 허용 반경, Recall·Precision·F1을 그대로 사용했다. 각 공식 스냅샷 시각을 포함하는 누적 판서를 평가한다. 숫자는 threshold=10의 스냅샷 평균이며 20/30도 각 JSON에 있다. 공식 unique-CC 요약 점수는 아니다.

| 영상 | 이전 누적 판서 수 → 현재 | 이전 A F1 | 현재 A R / P / F1 | 현재 B R / P / F1 |
|---|---:|---:|---:|---:|
| Lecture 01 part 1, training, GT 3개 | 4 → 4 | 96.80% | 99.53 / 94.12 / 96.75% | 99.53 / 94.12 / 96.75% |
| Lecture 02, testing, GT 10개 | 15 → 16 | 99.59% | 99.99 / 99.81 / 99.90% | 99.99 / 99.81 / 99.90% |
| Lecture 06 part 1, 추가 training, GT 4개 | 별도 신규 영상 → 6 | 없음 | 99.98 / 95.23 / 97.54% | 99.98 / 95.23 / 97.54% |

일반 실행의 26장 모두 B가 원본을 유지했다. 따라서 위 표에서 **B의 합성 이득이 입증됐다고 주장하지 않는다.** Lecture 01의 기존 141개 세부 상태 기준선 F1 83.28%와 비교하면 현재는 4장/96.75%지만, 이번 직전 누적 A 96.80%보다 점수는 0.05%p 낮다. 개선이 전 구간에서 단조롭지 않다.

Lecture 02의 441.708초 행렬 상태는 이전 누적 A 96.73%에서 현재 약 99.96%로 개선됐다. 이전에는 491초경의 작은 행렬 수정이 전체 판서량 기준에 묻혔다. 이제 수정 전/후 상태가 모두 남는다. 판서 수 자체가 품질 지표는 아니며 16장 각각의 원본은 비교 HTML에 있다.

## 확인한 원인과 수정

**607초 대표 선정.** 이전 코드의 가림 우선 순위에서 깨끗한 607.607초의 추정 가림은 43.32%, 교수자가 있는 616.1155초는 39.47%여서 후자가 33개 후보 중 1위였다. 선명도가 높아서 선택한 사례는 아니었다. [보존된 실제 후보·코드 경로 진단](../experiments/accessmath-improvement/diagnosis/candidates-607.html)을 참고한다. 현재는 전체 누적 판서의 말기 필기 노출·가림·불일치를 점수화한다. 해당 완성 판서는 365.866–652.152초이며 **640.1395초의 깨끗한 원본**을 선택한다. 607.607초도 후보와 근거로 보존하며 GT 시각과의 거리를 선정에 사용하지 않는다. [현재 세 후보 점수](../experiments/ab-refinement/review/607-candidates.json)와 전체 후보 JSON 링크가 있다.

**흰 칠판·옷·조명 분리.** 기존 어두운 칠판 오분류는 절대 밝기와 그림자의 영향이었다. 현재는 가림을 제외한 얇은 필기 극성을 사용한다. 이번 추가 조사에서는 남색 줄무늬 옷을 매끄러운 칠판 조명으로 맞추면서 몸통의 삼각 영역을 필기로 인식하는 실패를 원본/마스크에서 확인했다. 표면 적합에 타일 색차와 밝기의 강건한 가중치를 주고, 두꺼운 전경에 연결된 피부 영역을 포함했다. 이는 사람 검출 모델의 정확도를 보장하는 방법은 아니다.

**상태 경계.** 추가 필기는 누적하고, 가림 속 부재는 삭제에 투표하지 않는다. 전체 비율에 묻히던 작은 수정은 국소적인 필기 소실로 확인한다. 다만 작성 중인 단어를 지웠다 다시 쓰는 과정은 새 완성 판서가 아니므로 주변의 최근 필기 활동과 안정 시간을 확인한다. 삭제 중간 장면의 고립된 1~3픽셀 점 잡음도 새 필기로 취급하지 않는다. Lecture 06의 435–443초 잔여 장면은 이 잡음 18개 때문에 별도 출력됐으며 최종에는 앞 판서의 근거 구간으로 합쳤다. 억제한 구간을 다음 주제에 붙이면 시각과 복원 소스가 섞이는 회귀가 발생해, 이전 판서의 시간/관측 목록을 연장하도록 수정하고 테스트했다.

**미세한 후보 차이.** 확인 필기 몇 픽셀 차이로 깨끗한 원본보다 교수자가 들어온 원본이 선택되기도 했다. 내용·점수·가림 차이가 5 분석 픽셀 이내인 후보는 동등 후보로 두고 전경이 적은 쪽을 우선한다. 8픽셀짜리 새 기호를 놓치지 않는 회귀 테스트도 유지한다. 후보와 점수를 모두 JSON으로 남긴다.

**카메라.** 전체 위상 이동값만으로 카메라 이동을 확정하지 않고 공동으로 보이는 배경 특징점/ECC로 검증한다. 작은 검증된 이동은 A의 분석 마스크를 정렬하며, 최종 필기/빈 영역 근거는 선택 원본 좌표로 다시 내보낸다. 출력 원본 픽셀을 공간 워핑하지 않는다. 불확실한 B 정렬 후보는 제외한다. 실제 카메라 이동과 사람 움직임을 일반적으로 완벽히 구분했다고 주장하지 않는다.

## B: 필요한 영역만 복원

A의 말기 필기뿐 아니라 **마지막으로 비어 있음을 확인한 시각/마지막 필기 관측 시각**을 영역별로 사용한다. 지운 후의 빈 영역보다 오래된 글자는 복원에 쓸 수 없다. 초기 작성 전 빈 화면이 나중에 드러난 글자의 합의를 희석하지 않게 시간별 관측 자격도 계산한다. 같은 누적 판서·삭제 경계·배경 정렬을 확인하고, 다른 위치에 글자가 추가됐다는 이유로 원본 전체를 버리지 않고 충돌 영역을 제외한다.

B는 실제로 가린 칠판 영역이 있을 때만 시도한다. 테두리/선반의 팽창 마스크 여유분만 겹친 경우 원본을 유지한다. 이 검사가 없으면 교수자가 없는 원본의 선반을 불필요하게 교체하는 실패가 있었다. 복사 후 검사는 실제 전경 중심과 안전 여유분을 구분한다. 이 구분이 없으면 남겨둔 몸통의 팽창 여유분이 깨끗하게 복사한 영역까지 침범해 유효한 부분 복원을 계속 기각했다.

같은 영역을 1초 이상 떨어진 두 원본에서 확인하고 실제 픽셀을 복사한다. 공동으로 보이는 빈 칠판으로 검증된 밝기 보정을 적용할 수 있으며 계수도 출처에 저장한다. 생성·인페인팅·공간 보간은 없다. 원본의 가림 영역 밖 픽셀은 그대로 유지하며, 다른 원본 하나로 대체할 때도 A에서 보이던 필기를 잃지 않도록 검사한다.

## 실제 가림 구간 능력 시험

일반 A 결과와 구분해 자연스러운 연속 가림 구간 8개를 고정했다. 모든 0.5초 관측에서 중앙의 확인 필기 2% 이상이 가려지고, 공동 가시 내용이 유지되는 4–20초 구간을 소스만으로 찾았다. 구간 내부 관측만으로 A·말기 근거·B를 다시 만들고, 구간 밖의 깨끗한 참고 원본은 B가 끝난 후 평가에만 읽었다. 임의로 인물을 붙인 합성 영상이 아니다. 다만 전체 강의를 대표하는 무작위 표본도 아니다.

**7건은 합성/부분 복원, 1건은 검증 실패로 원본 유지**다. 고정된 이전 B는 모두 원본이었다. 참고 원본 기준 평균은 다음과 같다. 공식 GT 점수와 합산하지 않는다.

| 출력 | Recall | Precision | F1 |
|---|---:|---:|---:|
| 구간 A / 이전 원본 유지 B | 96.72% | 48.12% | 63.48% |
| 수정 B | 99.22% | 73.48% | 83.23% |

픽셀 F1은 옷무늬의 오검출 제거에도 반응하므로 이를 글자 수나 사용자 가독성의 직접 지표로 해석하지 않는다. 실제 이미지도 함께 확인했다.

- 330.831–340.840초: F1 82.76→99.97%, 반복 관측한 가려진 필기를 드러낸 개선 사례.
- 1885.884–1891.890초: 66.67→94.10%, 칠판 위 주요 가림은 줄지만 영상 하단 몸통은 남는다.
- 591.091–598.097초: 60.71→85.85%이나 몸통 일부와 밝기/패치 경계가 남는 시각적 실패도 함께 제시했다.
- 2158.156–2162.160초: 필기 보존 검증을 통과하지 못해 원본을 유지한다.
- 개발 중 `b00054` 원본 교체는 98.44→93.39%로 악화됐다. A에만 보이는 글자를 잃는 교체였고 현재 보호 규칙으로 막는다. 이 결과를 현재 채택 B로 표시하지 않는다.

채택 7건은 출처의 원본·사각형·밝기 보정 계수로 다시 만들었을 때 PNG와 픽셀 단위로 일치했다. 수정 영역 밖은 A와 동일하고, 구간 밖 원본은 합성에 쓰지 않았음을 확인했다. [검증 JSON](../experiments/ab-refinement/provenance-verification.json)에 있다.

1885초·433초 두 구간은 원본의 모든 프레임 180+120장도 추가 검사했다. 가장 덜 가린 프레임에서도 알려진 필기 397/16970, 532/9276픽셀이 가림 마스크와 겹쳤다. 휴리스틱 검사의 결과이며 인간 마스크 정답을 대신하거나 모든 구간에 깨끗한 원본이 없다는 증명은 아니다.

별도 통제된 합성 영상도 최종 코드로 실행했다. 1개 판서, A F1 88.62→B 99.88%다. 이는 위 실제 영상 결과와 별개다.

## 완료된 범위와 남은 것

구현·실행을 마친 것은 누적 판서 단위 A, 작은 수정 보존, 원본 우선 B, 시간별 삭제 근거, 영역 출처/밝기 보정 재현, 안전 실패 시 원본 유지, 실제/합성 구분 평가다. 테스트는 **48개 통과**했지만 품질 근거는 실제 수치와 이미지다. 실제 브라우저에서도 4장 표시, 640.1395초 대표 원본, A/B 전환, B 원본 유지 사유와 근거 572개 표시를 확인했다. [뷰어 화면](../experiments/ab-refinement/review/viewer-A17-B19.png)을 남겼다.

남은 주요 문제는 부분 복원의 계단 모양 경계와 잔여 인물, 칠판/옷/그림자 추정 오차, 가려진 동안의 수정, 극히 짧거나 작은 필기의 보존이다. 모든 강의에서 교수자가 없는 완성 판서를 안정적으로 얻는 수준은 아니다. 따라서 **A/B의 일반 실사용 품질이 끝났다고 선언하거나 C로 넘어가지는 않았다.** C의 OCR·수식/LaTeX·발언 보정·노트 생성은 미구현 상태로 둔다.

Lecture 02는 공식 testing 소속이지만 이미 개발 진단에 사용했다. Lecture 06은 training이며 최초 A14를 GT 열람 전에 고정했으나, 최종 A17에는 그 소스의 삭제 잡음 수정도 반영됐다. 최종 결과를 엄격한 미사용 testing 성능으로 주장할 수 없다. GT는 알고리즘 입력으로 쓰지 않았고 평가 함수도 바꾸지 않았다. Lecture 06의 원본 MTS→MP4는 영상 스트림을 복사하고 오디오만 AAC로 바꿨으며 픽셀/해시 근거는 데이터셋 provenance JSON에 남겼다. 아나모픽 원본은 기존 평가 함수대로 GT 크기로 맞췄고 정합 오차도 저장했다.

## 재현

최종 코드 버전은 `pages-17`, `page-restoration-19`, 전경 측정 `quality-6`이다. 입력/코드 해시는 각 accepted 폴더의 `algorithm.json`, 전체 비교는 `review/summary.json`에 있다. `validation/A17-full-tests.log`에 테스트 실행 결과가 있다.

```bash
# 기존 디코드/측정은 재사용하고 새 실험의 판서 결정을 재계산
.venv/bin/python scripts/board_pages_regroup.py experiments/ab-refinement/a-lecture01
# A를 보존하고 B를 별도 새 폴더에서 실행
.venv/bin/python scripts/restore_board_pages.py \
  --record experiments/ab-refinement/a-lecture01 --out experiments/my-ab-run
# 공식 GT는 이 평가 명령에서만 사용
.venv/bin/python scripts/evaluate_page_outputs.py \
  --record experiments/my-ab-run --previous experiments/board-pages/lecture01 \
  --gt datasets/accessmath/annotations/data/annotations/AccessMath2015_lecture_01 \
  --split training --out experiments/my-ab-evaluation
# 고정 실제 가림 입력으로 B만 재평가
.venv/bin/python scripts/replay_real_intervals.py \
  --frozen experiments/ab-refinement/real-intervals01 \
  --record experiments/ab-refinement/a-lecture01 --out experiments/my-interval-B
.venv/bin/python scripts/ab_refinement_review.py
.venv/bin/python -m pytest -q
.venv/bin/lecture2doc serve --record experiments/ab-refinement/accepted/lecture01 --port 8885
```
