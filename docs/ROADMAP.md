# 단계별 개발 범위

2026-11-02 사용자 합의 기준. 이전 실험 보고서는 당시 결과로 보존하며, 이후 개발 범위는 이 문서를 따른다.

## 현재 상태

A는 누적 판서 선택·원본 근거·탐색, B는 관측 기반 부분 복원까지 구현했다. 남아 있는 인물과 패치 경계는 후속 전처리 개선 과제로 두고 C를 진행한다. 기존 음성 전사 및 자막 입력은 구현돼 있지만, AccessMath 시연에서는 전사를 생략했다. C는 로컬 OCR을 구현했고 D는 아직 구현하지 않았다.

## V1 — A + B + C

첫 완성 버전의 이름은 **V1**이다. A는 누적 판서 선택, B는 관측 기반 복원, C는 OCR을 담당한다.

## C — 판서 OCR

- A/B 판서 이미지의 문자를 인식해 텍스트로 기록한다.
- 인식 영역의 좌표·원본 crop·입력 해시·모델 정보·원본 근거를 보존한다.
- 웹에서 판서별 텍스트와 원본 영역을 확인하고 텍스트를 복사한다.
- 영문 / 한글·영문 로컬 엔진을 선택한다. 음성 전사 없이도 실행한다.

**수식 인식·LaTeX 변환은 C와 V1의 완료 조건에서 제외한다.** 후속 목표로 남기며, 이미지 입력 API 활용도 이후 비교한다. 수식 원본 이미지는 A/B에 보존한다.

C의 로컬 OCR·CLI·영상 파이프라인·웹 표시를 구현했다. 실제 실행과 남은 오류는 [V1 OCR 실행 보고서](V1_OCR.md)에 정리한다. 모델 조사 근거는 [손필기 OCR 조사](HANDWRITING_OCR_SURVEY.md), 이전 후보 조사는 [C 서베이](C_SURVEY.md)에 남긴다.

## D — 강의 노트 활용

- 판서와 전사를 참고한 음성 전사 보정 제안. 전사 원문은 보존한다.
- 판서·설명을 묶은 강의 노트 정리와 근거 연결.
- 인식 결과 검토·수동 편집 기능.
- 인식된 판서·수식·설명의 통합 검색.
- Markdown 등 문서 내보내기.

기존 원본 영상 탐색·전사문 검색은 유지한다. D는 향후 범위이며 C의 완료 조건에 포함하지 않는다.
