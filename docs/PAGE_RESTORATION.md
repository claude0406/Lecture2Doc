# 누적 판서 B 복원 — 구현·실행 결과 (2026-11-02)

> 이 문서는 이전 기준선 보고서입니다. 최신 실행·수치·남은 실패는 [A/B 재평가](AB_REFINEMENT.md)를 확인하세요.


**누적 판서 단위의 B를 구현하고 웹·CLI에 연결했다.** 깨끗한 원본이 있으면 우선 사용하고, 필요한 경우 실제 원본 영역을 합성한다. 현재 실제 AccessMath 정상 결과에서는 추가 합성을 채택하지 않았다. 합성 영상에서는 전체 파이프라인 합성에 성공했으며, 실제 영상에서의 일반적인 합성 품질 개선은 아직 입증하지 못했다.

## 확인된 결과

| 실험 | A | B | 해석 |
|---|---:|---:|---|
| Lecture 01 part 1, 공식 GT 3개, F1 | 96.80% | 96.80% | 4개 판서 모두 깨끗한 A 원본 유지 |
| Lecture 02 testing, 공식 GT 10개, F1 | 99.59% | 99.59% | 8개 원본 충분, 7개 관측·일치 근거 부족으로 원본 유지 |
| 실제 616.1155초 실패 원본 회복 진단, 공식 GT 비교 F1 | 73.27% | 96.39% | B가 더 잘 보이는 609.1085초 원본 선택. **합성 성공 사례는 아님** |
| 별도 합성 영상, F1 | 88.62% | 99.88% | 모든 원본에 가림이 있지만 다른 위치가 드러나므로 영역 합성 성공 |

정상 Lecture 01의 A/B Recall·Precision·F1은 각각 **99.51 / 94.25 / 96.80%**, testing은 **99.71 / 99.47 / 99.59%**다. 판서 개수도 A의 **4개 / 15개**를 유지한다. B는 A의 경계·대표 선택을 덮어쓰지 않는다. 기존 141개 기준선 및 A 실험 결과는 그대로 보존했다.

실제 실패 원본 회복 진단은 과거의 잘못된 원본을 의도적으로 기준 이미지로 지정한 별도 실험이다. 정상 A는 이미 644.644초 원본을 고르므로 정상 A/B 성능 향상으로 합산하지 않는다. GT는 복원이 끝난 후 평가에서만 읽는다.

합성 영상은 16초 MP4, 원본 관측 32개, 누적 판서 1개다. 각 원본에는 왼쪽 또는 오른쪽 필기를 가리는 인물이 있고, 깨끗한 전체 원본은 없다. B는 감지된 가림 영역을 다른 원본으로 대체해 필기를 드러냈다. Recall **86.41→100.00%**, Precision **90.94→99.75%**, F1 **88.62→99.88%**이며, 20/30 threshold 결과도 JSON에 기록했다. 이는 **통제된 합성 실험**이고 실제 강의 복원 성능으로 해석하면 안 된다.

원본 영역 출처를 따라 모든 사각형을 다시 붙여 최종 PNG와 픽셀 단위로 일치하는지도 확인했다. 밝기 보정이 적용된 경우에는 보정식까지 재생한다.

## 실제 가림 스트레스 테스트와 기각 사례

깨끗한 관측을 의도적으로 제외한 별도 source-only 스트레스 테스트를 실행했다. Lecture 01에서 8개, testing에서 11개 세부 상태가 대상이 됐으며 **19개 모두 합성을 채택하지 않고 원본을 유지했다.** 같은 세부 상태의 실제 가림 원본만 사용한 보수적인 능력 시험이다. 정상 누적 판서 실행과 구분하며, 비교 참고 이미지는 공식 GT가 아닌 보류한 원본 관측이다.

기각한 합성 후보도 남겼다. `rejected-proposal-review.json`은 복원 종료 후 참고 원본과 비교한 진단으로, 채택된 B 결과가 아니다.

- Lecture 01 `b00054`: 후보를 그대로 채택하면 F1이 약 **98.44→98.04%**로 낮아진다. 밝기 차이·안전한 필기 이득 부족으로 기각했다.
- Lecture 01 `b00112`: 픽셀 F1은 후보에서 올라가지만, 교수자 일부와 영역 경계가 남아 시각적으로 부적절하다. 잔상 검사에서 기각했다. **픽셀 점수 상승만으로 복원 성공이라고 판단하지 않았다.**

따라서 이번 결과는 “실제 영상에서 교수자를 안정적으로 지우는 B가 완성됐다”는 증거가 아니다. 구현·원본 우선 정책·출처 재현·통제된 합성 동작은 확인했고, 실제 부분 합성은 계속 해결해야 할 과제다.

## 구현 정책

`lecture2doc/page_restore.py`가 새 누적 판서 복원을 담당한다. 기존 중간 상태 복원은 유지하며, 새 결과는 `manifest.page_reconstructions`로 구분한다. `page_reconstruction_status`, `reason`, `quality_flags`로 원본 유지와 합성을 명시한다. 웹은 B를 기본으로 보여주고 A와 전환할 수 있다. 등록 설정에서 A만 실행할 수도 있다.

1. A의 대표 원본에서 판서가 충분히 보이면 그대로 사용한다. 교수자가 판서를 가리지 않고 가장자리에 있다는 이유만으로 지우지 않는다.
2. A가 누적 관측한 말기 필기 마스크를 **확인된 필기의 양성 근거**로 사용한다. 마스크에 없는 모든 픽셀이 빈 칠판이라는 뜻으로 해석하지 않는다.
3. 같은 누적 판서 안에서 후보를 탐색한다. 가까운 원본, 시간상 분산된 원본, A의 대안을 함께 검토한다. 확인된 삭제·수정 경계는 넘지 않는다. 추가·움직임으로 나뉜 세부 상태를 넘을 때도 말기 필기·보이는 글자 일치 검사를 적용한다. 말기 근거가 없으면 같은 세부 상태의 주변 12초로 제한한다.
4. 배경 특징점 또는 공동으로 보이는 칠판의 ECC로 정렬을 검증한다. 교수자 때문에 전체 화면 위상 이동값이 커졌다는 이유만으로 카메라 이동으로 단정하지 않는다. 불확실한 정렬은 제외하며 출력에 공간 워핑을 적용하지 않는다.
5. 원본끼리 보이는 글자가 충돌하면 제외한다. 영역을 가져올 때는 1초 이상 떨어진 두 관측에서 가림이 없고, 글자와 색이 일치하는지 확인한다. 새로 붙일 필기는 누적 말기 근거와도 일치해야 한다.
6. 다른 원본 하나로 필기가 충분히 드러나면 합성 대신 그 원본을 사용한다. 타일을 고를 때는 날카로운 교수자 옷무늬보다 전경으로부터의 여유 거리를 우선한다.
7. 원본의 가림 마스크 안에만 실제 영역을 붙인다. 그 밖의 픽셀이 A와 완전히 같은지 검사한다. 작은 부분까지 안전하게 복사할 수 없으면 그 부분은 A로 유지한다.
8. 그림자 때문에 필요하면 **두 원본에서 함께 보이는 빈 칠판**으로 추정한 부드러운 밝기 오프셋만 적용한다. 글자를 만들거나 숨겨진 글자를 추론하지 않는다. 보정 계수·좌표계·오차를 영역 출처에 기록하며 보정한 값은 원본 RGB와 같다고 주장하지 않는다.
9. 합성 후 가림 잔상·필기 보존·실제 추가 노출을 검사한다. 안전하지 않은 영역을 제거해 재검사하고, 유효한 이득이 없거나 검증이 실패하면 합성 전체를 취소한다. 기각 후보는 진단용으로만 저장한다.

영역별 출처 JSON에는 기본 원본, 출력 좌표, 복사한 원본 ID와 좌표, 별도 대조 관측 ID, 필요시 밝기 보정 계수가 있다. 웹의 근거 썸네일에는 B 사용 원본과 대조 관측을 표시한다. 영역 지도는 **초록=대체, 빨강=미확인 가림 유지**다. 합성 여부가 같아도 “교수자가 영상 전체에서 사라졌다” 또는 “모든 미관측 필기가 복원됐다”는 뜻은 아니다.

새 모델·새 의존성은 추가하지 않았다. 기존 OpenCV·NumPy 및 가림·필기·배경 특징점 분석을 사용한다. 가림·필기·조명 추정은 휴리스틱이며 피부·옷·판서 색이 비슷하거나 작은 수정이 있으면 실패할 수 있다. A의 잘못된 경계와 누락된 말기 필기 근거도 B를 제한한다. 계속 가려져 한 번도 보이지 않은 글자는 복원할 수 없다.

## 평가·검증과 파일

공식 평가의 이진화·Recall·Precision·F1 계산은 기존 `accessmath_evaluate.py` 함수를 그대로 사용한다. 새 래퍼는 실제 `page_B` 이미지를 추가 비교한다. 누적 판서는 GT 시점 이후의 작성 내용도 포함할 수 있으므로 공식 unique-CC 요약 점수가 아닌 기존 스냅샷 진단 점수라는 한계도 유지한다.

- `experiments/page-restoration/release/lecture01/`, `release/lecture02-testing/`: 정상 실행, 원본 우선·기각 이유와 캐시 체크포인트.
- `evaluation-lecture01/index.html`, `evaluation-lecture02-testing/index.html`: GT·원본·기존 결과·새 A/B 비교.
- `synthetic-complementary/comparison.jpg`, `evaluation.json`: 합성 영상 결과·정량 지표·픽셀 출처 재현.
- `actual-source-rescue/comparison.jpg`, `result.json`: 실제 원본 재선정 진단.
- `stress/*/index.html`, `rejected-proposal-review.json`: 실제 가림 관측 시험과 기각 후보 진단.
- `ui-check.json`, `viewer-synthetic-A.png`, `viewer-synthetic-B.png`: 실제 Chromium에서 B 기본 표시, A/B 전환, 출처 JSON·영역 지도·원본 근거 확인.
- `tests-final.txt`: 전체 자동 테스트 **38개 통과**. 픽셀 출처, 다른 판서 제외, 삭제 경계, 세부 상태 연결, 원본 우선, 밝기 보정 재현을 포함한다. 통과 수를 실제 품질 향상의 근거로 대신하지 않는다.

```bash
# 새 영상은 기본 A+B, A만 실행하려면 --no-reconstruct
.venv/bin/lecture2doc process lecture.mp4 --out data/new-record

# 보존된 A 결과에 B 실행: 반드시 별도 출력 폴더
.venv/bin/python scripts/restore_board_pages.py \
  --record experiments/board-pages/lecture01 --out experiments/page-restoration/reproduction

# 실제 영상 결과 / 합성 예제 결과
.venv/bin/lecture2doc serve --record experiments/page-restoration/release/lecture01 --port 8880
.venv/bin/lecture2doc serve --record experiments/page-restoration/synthetic-complementary/record --port 8881

# 합성 입력 생성 → 전체 파이프라인 → 별도 평가
.venv/bin/python scripts/page_restoration_demo.py
.venv/bin/python scripts/page_restoration_demo_evaluate.py

# 실제 가림 스트레스 시험 (정상 A/B와 별도, 공식 GT 입력 없음)
.venv/bin/python scripts/page_restoration_challenge.py \
  --record experiments/board-pages/lecture01 --out experiments/page-restoration/stress-reproduction
```
