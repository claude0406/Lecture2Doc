# 검증 기록 · 2026-11-01

코드 실행과 판서 보존 품질을 별도로 평가했습니다. 자동 테스트 통과를 실제 강의 품질 보증으로 취급하지 않습니다.

**추가 검증:** 이후 AccessMath 1080p 파일 전체(17분 26초)를 실행하고 공식 정답 키프레임 3개를 비교했습니다. 새 결과와 실패 사례는 [ACCESSMATH.md](ACCESSMATH.md)에 있습니다. 앱 알고리즘은 바꾸지 않았습니다.

## 자동 검증

`python -m pytest -q`: **15개 통과**. Linux x86_64 / Python 3.11, CPU 실행. 사용자 Intel 268V/Arc 환경의 실측은 아닙니다.

검증 항목은 8개 합성 영상의 시간 순서·상태 순도·원본 샘플의 완전한 상태 배정·원본 해상도·중복 억제, 전사 실패 시 판서 보존, 입력 변경 거부, 단계 캐시, VTT 원문 보존, 웹 업로드·HTTP Range 탐색·경로 탈출 및 Host/CSRF 제한, 복원 타일과 출처 원본의 픽셀 일치, 분석 실패 시 자막 보존, 가변 프레임률 PTS, 화이트보드 같은 위치 재작성 및 비파괴 재실행입니다.

정확한 자동 테스트 출력은 [test-results.txt](test-results.txt)에 저장했습니다. UI는 실제 Chromium에서도 실행해 데스크톱/390px 모바일 이미지 표시, A/B 전환, 전사 원문 안전 표시, 검색, 원본 시점 이동, 가로 넘침 없음을 확인했습니다. 브라우저 JavaScript 오류는 관측되지 않았습니다. [데스크톱](viewer-desktop.png), [모바일](viewer-mobile.png) 화면을 남겼습니다. MP4V 입력을 자동 생성 H.264 사본으로 재생하고 근거 프레임을 눌러 4초 시점으로 이동하는 것도 실제 브라우저에서 확인했습니다.

## 합성 품질 평가

생성기: `scripts/fixtures.py`. 1280×720, 6fps. 7종은 12초, 긴 유지 영상은 40초. 입력은 의도적으로 단순한 배경·얇은 흰 필기·뚜렷한 단색 전경입니다. 실제 사람이나 복잡한 그림의 대표 표본이 아닙니다.

실행: `python scripts/evaluate.py --root experiments/validated`.

- [종합 비교 HTML](../experiments/validated/index.html)
- [기계 판독 결과](../experiments/validated/report.json)
- 각 상태에 대해 최초 원본 관측 / A 선택 원본 / B 결과 / 알려진 판서 정답을 나란히 저장했습니다.

판서 픽셀 회수율은 정답의 밝은 분필 픽셀(화이트보드는 어두운 픽셀) 중 결과와 각 색 채널 차이가 35 미만인 비율입니다. OCR 정확도, 인간 가독성, 가림 마스크 정확도, 새로운 오필기 생성률을 모두 표현하는 점수가 아닙니다. 예를 들어 필기 바깥의 교수자 잔상이 있어도 회수율이 높을 수 있으므로 비교 이미지를 함께 봐야 합니다. 상태 순도는 생성기의 실제 판서 라벨이 하나의 상태에 섞였는지 검사합니다.

| 시나리오 | 상태 수 | 관측 결과 |
|---|---:|---|
| 점진 완성 | 4 | 빈 상태와 1·2·3줄 상태 분리. 각 선택 원본 판서 픽셀 100% |
| 교수자 가림·이동 | 1 | 선택 원본 64.85% → 부분 복원 82.65%. 타일 경계에서 검증되지 않은 부분은 남음 |
| 일부 삭제 | 2 | 삭제 전/후 분리, 선택 원본 100%. 원본 제공 |
| 같은 위치 재작성 | 2 | A/B 분리, 혼합 없음. 원본 제공 |
| 컷 전환 | 2 | 칠판/화이트보드 장면 ID 분리. 원본 제공 |
| 필기 변화 없이 움직임 | 1 | 불필요한 상태 증가 없음. 관측 합성 후 필기 100%, 사람 잔상은 별도 시각 확인 필요 |
| 긴 동일 상태 | 1 | 시간 경과만으로 중복 생성하지 않음. 원본 제공 |
| 필요한 정보가 전혀 보이지 않음 | 1 | 원본 14.07% 그대로. 복원 개선을 주장하지 않음. 원본 제공 및 미확인 영역 경고 |

이 8개 입력에서 판서 라벨이 섞인 상태는 없었습니다. 같은 위치 A/B를 합성한 사례도 관측되지 않았습니다. 이는 일반 입력에서 잘못된 합성을 방지한다는 증명이 아닙니다.

초기 실행에서 정상 정지 영상도 코덱 차이를 조합해 `composited`로 표시하는 문제가 있었습니다. 현재 버전은 선택 원본의 전경 마스크와 겹치는 타일만 대체합니다. 구버전 실험 디렉터리는 작업 이력일 뿐, 위 결과는 `experiments/validated/`를 기준으로 합니다.

합성별 최초 실행은 약 1.7~3.7초였습니다. 환경 부하·PNG 압축·짧은 영상의 영향이 크며, 실제 1080p 전체 강의 처리량으로 외삽할 수 없습니다. 강의 전체를 대상으로 누락률·중복률·처리 속도를 정량 평가하지 않았습니다.

## 실제 영상 실행

출처: Prof. David Jerison, MIT OpenCourseWare, **18.01 Single Variable Calculus, Lecture 1: Rate of Change**. [공식 강의 페이지](https://www.ocw.mit.edu/courses/18-01-single-variable-calculus-fall-2006/resources/lecture-1-derivatives/)의 공개 [다운로드](https://archive.org/download/MIT18.01JF07/ocw-18.01-f07-lec01_300k.mp4)를 사용했습니다. CC BY-NC-SA 4.0. 시작 180초부터 45초를 H.264/AAC로 자른 로컬 분석 사본입니다. 재현 명령은 [real_example.sh](../scripts/real_example.sh)에 있습니다.

- 실제 입력: 480×360, 약 29.97fps, 45.011초, 오디오 있음. 720p 요구에 미달하고 카메라 이동이 있음.
- ROI: `0.1,0,0.85,0.74`, `blackboard`, 0.5초 관측.
- 관측 원본: 90개. 판서 상태: **46개**, 복원 결과 **46개 모두 fallback**.
- 실제 음성: faster-whisper **tiny / CPU int8 / en**, **6개 구간** 생성. 모델 다운로드 후 추론 성공. 정답 대조 WER/CER 및 한국어 전사 평가는 수행하지 않음.
- [실제 manifest](../experiments/real/record/manifest.json), [비교 요약](../experiments/real/record/comparison-summary.json), [비교 1](../experiments/real/record/comparison-1.jpg)부터 4페이지.

시각 확인에서 교수자 가림·이동이 필기 변화로 계상되고 저해상도 경계 차이가 상태 수를 증가시키는 문제가 보였습니다. 초기 전체 화면 설정은 51개 상태였고 ROI와 경계 흔들림 허용을 적용해도 46개였습니다. 이 결과를 실제 판서 복원 성공이나 A단계 실사용 품질 검증으로 보고하지 않습니다. 보수적 복원 거부 및 원본·전사 보존이 작동한 실패 사례입니다.

실제 영상 비교 자료에는 가림 없는 정답이 없으므로 네 번째 열은 선택 원본 참조이며 정답이라고 표시하지 않았습니다. 합성처럼 회수율을 수치화하지 않았습니다.

## 남은 검증과 기능

아래는 AccessMath 추가 실행 이전의 재현 안내입니다. 현재는 [AccessMath 1080p의 학습 분할 일부](ACCESSMATH.md)를 실제 실행했습니다. 추가 실제 강의와 공식 테스트 분할 검증이 필요하며 다음 명령으로 같은 실험을 수행할 수 있습니다.

```bash
lecture2doc process /path/real-fixed-camera-1080p.mp4 \
  --out experiments/real-1080p --roi 0.05,0.05,0.9,0.8 \
  --board blackboard --subtitles /path/real.srt --make-playback
python scripts/evaluate.py --record experiments/real-1080p
lecture2doc serve --record experiments/real-1080p
```

추가로 인간이 중요한 판서의 등장/완성/삭제 직전 시각, 실제 가림 마스크, 같은 위치 재작성 구간을 표기해 회수율과 잘못된 합성을 평가해야 합니다. AccessMath의 공식 키프레임 정답 일부를 평가했지만, 가림 추정의 일반화, 정지한 교수자, 같은 색 옷, 복잡한 도식, 컬러 판서, 조명 변화, 전체 데이터셋 성능, 한국어 Whisper 정확도는 미검증입니다. C단계 OCR·LaTeX·AI 노트와 PDF는 미구현입니다.
